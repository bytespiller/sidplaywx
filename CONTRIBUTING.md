Please note that AI-generated contributions to [github.com/bytespiller/sidplaywx](https://github.com/bytespiller/sidplaywx) are not accepted.

The sidplaywx is a hobby project, not a product.

Even with careful prompting, AI tends to reshape the entire codebase really quickly, which results in that codebase becoming transformed and unfamiliar.
It's a [Ship of Theseus](https://en.wikipedia.org/wiki/Ship_of_Theseus) effect that overwhelms and alienates human programmers from the codebase they previously knew.

While the AI-generated changes make the project superior immediately, changes made without use of AI are slow, deliberate and minimal -- which is healthy for the codebase in the long term.

If you want to improve (transform) the sidplaywx using AI, feel free to create your own git fork and fire away. Don't forget to append your name & year to copyright labels in the code (and elsewhere).
